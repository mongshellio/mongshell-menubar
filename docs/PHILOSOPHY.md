# PHILOSOPHY

## Core Value Proposition

**확인하러 가지 않아도 되게 한다.**

이 앱이 없애려는 것은 작업 흐름을 끊는 왕복이다. Claude 구독 사용량은 CLI 를 열어 `/usage` 를 쳐야 보이고, 서버 맥의 상태는 접속해서 들여다봐야 안다. 이 앱은 그 답을 메뉴바에 상시 띄워, **아무것도 하지 않아도 눈에 들어오게** 만든다. 자세히 보고 싶을 때만 클릭한다.

주인공은 Claude 사용량이다. 메뉴바의 숫자는 5시간·7일 한도의 것이고, 그 밖의 것은 대상마다 신호등 점 하나로 접혀 곁에 붙는다.

따라서 이 프로덕트의 성공 조건은 기능 수가 아니라 **글랜스(glance) 품질**이다. 한 번 흘긋 봐서 "지금 여유가 있는가, 서버는 괜찮은가" 를 판단할 수 없다면 실패다.

## In Scope

- **메뉴바 상시 표시** — 5시간·7일 사용률, 그리고 놓치기 쉬운 5시간 창의 초기화 시각.
- **클릭 시 상세 팝오버** — 정확한 %, 두 한도의 초기화 시각, 모델별 주간 사용량, 계정 상태.
- **임계 상황 알림** — 색상 3단계 + 위험 시 맥동 + 시스템 알림.
- **곁들이는 상태** — 이 맥 또는 내가 운영하는 서버 한 대의 것 중 § Admission Criteria 를 통과한 신호. 서버라면 그 위에서 내가 의존하는 서비스(openclaw 게이트웨이)의 건강과, 서버가 곧 멈출 조짐(전원·디스크 등)이다.
- **Claude Code 설정의 GUI 편집** — CLI 를 열지 않고 자주 바꾸는 몇 개 키만.
- **혼자 쓰거나, 아는 사람에게 빌드해서 주는 배포.**

## Out of Scope

- **사용량 이력·통계·차트.** 지금 여유가 있는지가 질문이고, 어제 얼마를 썼는지는 아니다. 시계열 저장은 DB 를 부르고 앱의 성격을 바꾼다.
- **여러 계정 동시 표시.** 1인 1계정 전제. 계정 전환은 로그아웃/로그인으로 충분하다.
- **`settings.json` 의 전체 편집기.** `hooks`·`env`·MCP 같은 자유형 키는 GUI 로 안전하게 다룰 수 없다 — 5개 키만 다루고 나머지는 보존만 한다.
- **App Store 배포.** 비공식 엔드포인트와 Keychain 공유 접근이 심사·샌드박스와 양립하지 않는다.
- **공식 API 로의 전환 시도.** 구독 한도에는 공식 API 가 없다. 있는 것처럼 가장하지 않고, 비공식 의존이라는 사실을 README 에 명시한 채로 간다.
- **범용 시스템 모니터.** CPU·메모리·네트워크 같은 사용률 지표는 다른 앱의 일이다. 서버에 대해 받아들이는 것은 "곧 멈출 조짐" 뿐이고, 그것도 § Admission Criteria 를 통과한 것만이다.
- **원격 쓰기 동작과 다중 모니터링.** 원격 서버에 대한 재시작 같은 쓰기 동작, 여러 서버·여러 서비스의 모니터링은 하지 않는다. 원격 상태는 읽기만 하고, 복구는 서버 쪽이 스스로 한다.

## Admission Criteria

Claude 사용량 외의 신호가 새로 들어오려면 아래를 모두 만족해야 한다. 하나라도 걸리면 거절이다.

1. **왕복이 실재한다.** 지금 내가 실제로 확인하러 가고 있는 것이어야 한다. "있으면 좋을 것 같은" 지표는 해당하지 않는다.
2. **행동을 부른다.** 값이 나빠지면 내가 할 일이 생겨야 한다 — 어댑터를 꽂는다, 디스크를 비운다. 보고 넘어갈 뿐인 숫자는 통과하지 못한다.
3. **판정으로 접힌다.** 정상·주의·위험으로 줄일 수 있어야 한다. 추이를 봐야 의미가 생기는 값은 이력을 부르고, 이력은 범위 밖이다.
4. **메뉴바 가로 폭을 늘리지 않는다.** 메뉴바에는 대상마다 신호등 점 하나만 내고, 상세는 팝오버에 둔다. 폭을 늘리지 않고 들어갈 자리가 있을 때에만 원칙 1 의 "무엇을 뺄지" 요구를 면한다 — 자리가 없으면 원칙 1 이 그대로 적용된다.
5. **서버 밖으로 나가도 되는 값이다.** 서버에서 오는 신호라면, 판정과 표시에 쓰는 상태값만 내보낸다. 호스트명·계정명·경로·버전처럼 서버를 식별하거나 공격에 쓰일 수 있는 정보는 내보내지 않는다.

## Design Principles

1. **글랜스 우선, 클릭은 보조.** 메뉴바 폭은 유한하다. 상시 표시할 정보를 늘리는 제안은 기본적으로 거절이고, 늘리려면 무엇을 뺄지 함께 제시해야 한다.
2. **없으면 없는 대로 완전히 사라진다.** 선택 기능(openclaw, Claude Code 설정)은 그 전제가 이 맥에 없거나 설정되지 않았으면 메뉴바·팝오버·설정 어디에도 흔적을 남기지 않는다. "회색으로 비활성" 도 시각적 소음이다. 단, 이 맥에서 감지할 수 없는 전제(원격 서버 등)의 **설정 진입점**은 예외다 — 전제를 감지할 수 없으면 그 입력칸 말고는 기능을 켤 길이 없다. 서버가 보내지 않는 신호(배터리 없는 서버의 전원 상태 등)는 예외가 아니다 — 자리를 남기지 않는다.
3. **사용자의 파일은 손님의 물건이다.** `~/.claude/settings.json` 은 CLI 와 공유하는 사용자 자산이다. 앱이 모르는 것은 보존하고, 확신이 없으면 쓰지 않는다.
4. **Claude 자격증명은 이 맥을 떠나지 않는다.** Claude 자격증명은 Keychain 에만 있고 Anthropic 호스트 외 어디에도 전송하지 않는다. 텔레메트리·크래시 리포터를 붙이지 않는다.
5. **의존성 0 을 유지한다.** 외부 패키지 없이 Apple 시스템 프레임워크만으로 만든다. 외부 패키지 하나가 Xcode 없는 빌드와 재현성을 깨뜨린다.
6. **비공식성을 숨기지 않는다.** 엔드포인트가 언제든 막힐 수 있다는 전제로 만들고, 그 사실을 README 와 코드 주석에 남긴다.
